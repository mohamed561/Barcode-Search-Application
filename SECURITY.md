# Security Policy

## Supported Versions

The following versions of **BSA Barcode Search APP** receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | ✅ Supported       |
| < 1.0   | ❌ Not supported   |

## Reporting a Vulnerability

If you discover a security vulnerability in **BSA Barcode Search APP**, please report it as soon as possible.

- **Contact:** Send an email to **mohamedtroufi01@gmail.com** with details about the issue.
- **Response Time:** We aim to respond to security reports within **24 hours**.
- **Next Steps:** After reviewing your report, we will assess the issue and inform you about our plan to address it.

We appreciate responsible disclosure and will work quickly to fix any vulnerabilities! 🚀
